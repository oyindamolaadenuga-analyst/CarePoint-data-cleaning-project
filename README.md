# CarePoint Data Cleaning Project

# Project Overview
This project focuses on cleaning and transforming a messy healthcare dataset for CarePoint Clinic using Microsoft Excel. The goal was to improve data quality, consistency, and usability while developing practical data-wrangling skills.

## Data Cleaning and Transformation
The cleaning process included:
- Standardising patient IDs, names, gender, cities, visit types, diagnoses, insurance providers, clinicians, and notes
- Cleaning and validating ages, dates of birth, phone numbers, email addresses, and visit dates
- Standardising blood pressure values
- Converting temperature values to a consistent unit and flagging converted or missing values
- Cleaning and validating patient weight values
- Cleaning billing and payment information
- Calculating outstanding balances and reconciling payment status
- Identifying and handling missing or invalid values while retaining the original data for reference

## Tool Used
Microsoft Excel

## Deliverable
A cleaned and transformed CarePoint patient dataset with documented data-cleaning steps.
